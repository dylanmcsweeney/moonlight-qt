# Moonlight 7.1.1.3

Packaging correction for 7.1.1.2. The installed 7.1.1.2 executable had the correct streaming and keyboard changes but displayed 7.1.1.1 in the GUI. The display version now comes from a generated header tracked by the incremental build. This build carries the same receiver, input behavior and profile format as 7.1.1.2.
