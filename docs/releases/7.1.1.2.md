# Moonlight 7.1.1.2

This cumulative Windows x64 test build adds the Nonary streaming-core sync and extended keyboard input to [7.1.1.1](7.1.1.1.md).

## What to test

- In a streamed app that binds the keys separately, press main Enter and keypad Enter. Hold both, release one, then switch focus away from Moonlight. The host should distinguish both keys and release the remaining key when focus changes. Sunshine-derived hosts can receive extended key information. The streaming core strips the extension for legacy NVIDIA hosts.
- For PyroWave, compare the same wired stream and profile on both builds. With 7.1.1.2, a dropped packet at the end of a frame can cause less stutter. If a host sends intact packets in widely spaced batches, watch for a momentary loss of fine detail. On unprotected final blocks with all critical data present, the new receiver can deliver after 3 ms of silence, or after as little as 1.2 ms if a VRR presentation deadline is due. It first drains queued socket data. A deterministic 2.5 ms gap test retained the intact suffix without a known deadline and discarded it with a past deadline. The older receiver waited for the final packet or the next boundary.

## Integration record

- Local commit `c7a25f5f` updates the streaming core from `d6a11bc` to Nonary `064a4af` and adopts its C11 atomics build requirements (Nonary Qt `4c05b34e` and `f586143c`). Source review reconciled the upstream frame-loss and core updates represented by `14c26d8c`, `dc92b6d2` and `8016954c`. These include per-frame loss reporting and recovery after a lost multi-block frame. The underlying fork retains its controller and PyroWave extensions.
- Default PyroWave negotiation continues to advertise record framing only. Optional compression, link speed, and calibrated host pacing remain separate integration work. This build uses the existing settings and profile format.
- Local commit `c70e8078` follows upstream `b75fe0d9` and `c0f62ad6`. Main Enter and keypad Enter share a Windows virtual key code, so the client now tracks the extended modifier and original flags alongside the code of each held key. It sends them again during focus-loss cleanup.

## Verification

The Windows x64 release build uses Qt 6.11.1 and MSVC 14.52. Core tests covered the callback ABI, controller packets, independent motion slots, high-word button state, default SDP output, frame reassembly, UDP receive timeouts and the VRR pacing worker. Profile/navigation, GUI startup recovery, backend, bitstream, lifecycle and Basic/Material dialog regressions passed. The earlier release's warning parser, overlay and isolated paired-host sleep tests passed again.

The integrated keyboard fixture passed both release orders and verified the flags emitted during focus-loss cleanup. Local commit `1dadc440` fixes standalone CI linkage, verified by building the fixture against the production core and running all 18 checks. Independent Sol 6.2 Medium review verified the legacy NVIDIA modifier filtering and identified the PyroWave timing tradeoff documented above. The new receiver was selected for this A/B build.

Live GPU streaming, physical keyboard input, macOS compilation and an installed MSI upgrade remain interactive or platform-specific checks.
