# Moonlight 7.1.1.1

First cumulative MSI in the versioned integration series. Baseline: `8bd2689e`, the previously tested renderer/pacing/GUI reliability batch. The application version and Windows executable version are both `7.1.1.1`.

## Included changes

- Nonfatal host warnings: Nonary `3ae5f3b0` and `d54e6c04`, adapted in local commit `58ae53b9`. Successful launch/resume responses may supply a bounded, sanitized warning for the existing stream overlay. Known codes retain translated local text; unknown codes can use the host's plain-text explanation. The warning expires after approximately ten seconds and clears at teardown without clearing unrelated status messages.
- Confirmed paired-host sleep: Nonary `696afb07`, with the architecture-specific test dependency correction `cfef0e8d`, adapted in local commit `1b13be23`. The action is available only when advertised by a paired host, requires confirmation, and obtains a fresh one-use token over HTTPS pinned to that host's certificate. It starts no stream and does not automatically retry an unacknowledged sleep request.
- Versioned MSI assembly: fresh dependency staging, exact version checks, committed-source checks, app-local runtime dependencies, non-overwriting archives and a checksum/source manifest.

This version preserves the existing profile/settings format, VRR18/PyroWave settings and startup recovery. The streaming-core submodule remains at `d6a11bc`; the newer core is reserved for the next MSI.

## Validation

The warning increment passed its Windows release build, 42 launch/resume parser cases, overlay isolation/lifetime checks and the normal profile, startup, backend, bitstream and lifecycle suites. Independent Sol Medium review found no actionable issue in that increment or the packaging helper.

The sleep increment passed the same release build and normal gate: profiles 25, startup recovery 15, backend 5 and lifecycle helpers 6 QtTest checks, plus five bitstream boundary groups. Dialog tests passed under Basic and Material (33 each), and the Material toolbar regression passed (3). Sleep transport tests passed 20 QtTest checks against loopback TLS peers. The real AppView confirmation test passed under Basic and Material (3 each), and its Material capture was visually inspected with Windows fonts available to the offscreen platform. These fixtures never contact a configured host or perform a real power action.

Independent Sol Medium review found no actionable issue in the sleep product changes or tests. Luna Max implementation needed review-driven release-assertion, test-path quoting and certificate-success-check refinements; all were included before the final gate. The packaging helper's CRT staging order was corrected before use. A test-build PATH collision was fixed in the parent's local runner, without changing product code.

MSI assembly and extracted-payload verification are recorded with the artifact manifest after packaging.

## Artifacts and installation

Archive: `MoonlightSetup-x64-7.1.1.1.msi`, in the project root. Its adjacent `.msi.json` records the exact source revision and MSI/executable SHA-256 hashes. A committed copy of that manifest is added after successful packaging. Source tag: `codex/build-7.1.1.1`.

This is a normal upgrade from `7.1.0.0`. It uses the existing upgrade path rather than an uninstall/reinstall. Preparing this release does not install it. Live host warnings, host sleep, streaming/GPU behavior and actual installer upgrade behavior remain interactive validation items.
